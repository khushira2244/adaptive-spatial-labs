UNITY / QUEST
==================================================

Target:
Meta Quest mixed reality.

Use a current supported Unity LTS version already available in the project/environment.

Use OpenXR / Meta XR packages where appropriate.

Do not create a browser-style application outside Unity.

The Group 1 screens are panel-based setup/product screens displayed in MR.

They must be comfortable in headset:
- readable
- large touch/ray targets
- not overly dense
- consistent physical sizing
- seated-friendly
- usable with ray/controller interaction

==================================================
MR SCALE / PANEL RULES
==================================================

Create initial physical-space constants rather than arbitrary per-screen values.

Use approximate starting values:

Main application panel:
- width: about 1.15–1.2 meters
- height: about 0.68–0.72 meters
- default viewing distance: about 1.0–1.2 meters

Expanded sidebar:
- approximately 0.18–0.22 meters wide

Top bar:
- approximately 0.08–0.10 meters high

Controls:
- use large ray-friendly hit targets
- do not make buttons depend only on text bounds

These are initial constants that should be adjustable from one design-system location.

Do not hard-code physical dimensions independently in every screen.
